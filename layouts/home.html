❓ 自托管常见问题

自托管需要什么技术基础？

基本的 Linux 命令行使用即可。如果你会用 cd、ls、vim，就能跟着我们的教程完成部署。每个步骤都有详细的命令和截图指引。

一台 VPS 能跑多少个服务？

1 核 2GB 的入门 VPS 就能同时运行 5-8 个 Docker 容器（如 N8N + Vaultwarden + Uptime Kuma + Nginx + PostgreSQL）。2 核 4GB 能跑 15+ 个服务，完全够个人或小团队使用。

自托管比 SaaS 真的省钱吗？

一年省 80% 不是梦。以密码管理器为例：1Password 家庭版 $60/年，自托管 Vaultwarden 用 $5/月的 VPS 跑 10 个服务，均摊每个服务每月才 $0.5。一个服务就回本了。

最推荐的入门 VPS 是哪家？

Hetzner（欧洲）性价比最高，$4/月 2 核 4GB。国内用户选 阿里云轻量（香港节点），$5.5/月免备案。追求简单选 DigitalOcean，$6/月起步，文档完善。

❓ Self-Hosting FAQ

What technical skills do I need?

Basic Linux command-line skills (cd, ls, vim) are enough. Every tutorial includes exact commands you can copy-paste.

How many services can one VPS run?

A 1 vCPU / 2GB RAM VPS can run 5-8 Docker containers (N8N + Vaultwarden + Uptime Kuma + Nginx + PostgreSQL). 2 vCPU / 4GB handles 15+ services easily.

Is self-hosting really cheaper than SaaS?

80% savings are realistic. Example: 1Password family costs $60/year. Self-hosted Vaultwarden on a $5/month VPS sharing 10 services costs ~$0.50/service/month. One service alone pays for the server.

Which VPS provider should I start with?

Hetzner offers the best value ($4/mo for 2 vCPU / 4GB). For US users: DigitalOcean ($6/mo) with great docs. Asian users: Alibaba Cloud HK node (no ICP needed).
